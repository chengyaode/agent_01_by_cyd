# 周报生成技能

## 何时使用
用户提到"周报"、"工作总结"、"本周汇报"、"周报整理"等需求时。

## 步骤
1. **先查参考文档目录**:调用 `list_context_files` 看用户是否上传了参考资料。
   - 有 → 对每份文档用 `read_document` 读取内容,这些通常是用户提供的工作记录、会议纪要、日报原文,**优先用它们**。
   - 没有 → 再用 MCP 文件系统工具(`mcp__filesystem__*`)查看工作区 `workspace/` 下的 `notes/`、`log/`、`*.md` 等;还是找不到时向用户询问要点。
2. 用以下结构产出周报(按实际内容填充,不要空泛):
   - 本周完成(按项目分组,列出可验证的结果)
   - 进行中与风险(标注阻塞项与需要的支持)
   - 下周计划(3-5 条,可量化)
3. 将周报写入工作区 `reports/weekly-<yyyy-MM-dd>.md`,并在回复中给出摘要。

## 约束
- 语言使用简体中文,条理清晰,避免空话。
- 参考文档只读,不要修改或删除用户原件。
- 单份参考文档超过 12000 字符时会被自动截断,需综合多份材料拼凑完整信息。
- 如果参考文档和工作区内容冲突,以**参考文档为准**(那是用户明确提供的最新资料)。
