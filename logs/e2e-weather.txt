REPLY=在调用 `query_weather` 工具时，`forecast_days` 参数必须以 **字符串类型** 传递（例如 `"2"`），而非整数。错误提示表明系统检测到整数类型，但接口要求字符串。以下是修正后的调用示例：

```json
{
  "name": "query_weather",
  "arguments": {
    "city": "北京",
    "forecast_days": "2"
  }
}
```

**关键说明**：  
- 若需查询 **当前天气**，请设置 `forecast_days="0"`（字符串 `"0"`）  
- 若需查询 **未来3天**，请设置 `forecast_days="3"`（字符串 `"3"`）  

请确保参数始终使用双引号包裹的字符串（如 `"2"`），而非整数（如 `2`）。
